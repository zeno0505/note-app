# 읽기 전용 조회 정책 변경과 검증 조건

사용자의 UsageScope 동작 설명을 참고했다. 해당 앱을 조사·조작하지 않았다.
이번 요구는 읽기 전용 Orca/CodeBurn의 blur/hide 즉시 중단 정책을 대체한다.
과거 보고서의 pause/resume 검증은 당시 정책에 대한 기록이며 새 정책의 증거가 아니다.
production AI transport 차단과 모델 호출 0회를 유지한다.

## 동작

- 명시적 연결은 창 상태와 관계없이 한 번 즉시 수집한다. 전경은 기존 20초,
  배경은 5분 간격이다. 성공/실패 모두 완료 시점부터 다음 간격을 예약한다.
- 전경 복귀 시 main 소유 5초 카운트다운을 초 단위로 전달하고 재조회한다.
  다시 배경이 되면 카운트다운을 정리한다. 이미 전경인 focus/show 이벤트는
  타이머를 추가하거나 기한을 연장하지 않는다. hover 기능을 추가하지 않았다.
- 개요와 설정의 기존 ‘실제 소스 새로고침’ 버튼을 유지한다. 같은 이름·기능이며
  카운트다운 안내에서 즉시 조회 경로를 알린다. 중복 버튼은 추가하지 않는다.
  manual은 countdown을 즉시 지우고 진행 중인 요청에는 합류한다.
- blur/hide는 진행 중인 수집을 취소하지 않는다. 주기/복귀/manual 모두 하나의
  flight에 합류한다. 해당 flight가 끝날 때까지 새 loader를 만들지 않는다.
- 연결 해제/종료는 별도 stop/dispose로 전체 예약과 queued 요청을 정리하고
  signal abort·late 결과 차단을 유지한다. 재연결도 취소된 loader의 소유권이
  정리되기 전에는 새 loader와 겹치지 않는다. 요약 ticket/프로젝트 전환 경계는
  변경하지 않는다.
- 절전 복귀 때는 현재 시간 기준 한 번 조회하고 완료 후 다음 기한을 예약한다.
  지난 20초/5분 슬롯을 catch-up queue로 저장하지 않는다. 실패는 마지막 성공을
  유지하며 마지막 관측과 다음 조회 시각을 함께 보여 준다. 40초 freshness 기준은
  유지해 배경 관측을 5분 동안 최신이라고 포장하지 않는다.

20초 전경 주기는 연결된 실제 소스의 상태 변화를 계속 보여 주는 기존 동작을
유지하기 위해 남겼다. 배경 수집 빈도를 낮추며 동시에 한 번, 완료 기준 간격으로
제한한다. 카운트다운의 초당 publish는 복귀의 5초에만 발생하며 별도 수집이 아니다.
실제 Mac CPU/RSS/절전 전력 측정으로 자원 효과를 입증했다고 주장하지 않는다.
기본 snapshot 사용자의 기존 pause 정책은 opt-in 옵션이 없으면 유지된다.

## 검증과 남은 게이트

fake clock으로 5분 배경 조회, 5→1 카운트다운, hide 재진입 정리, 반복 focus,
manual/periodic/resume 합류, 최대 1 flight, countdown 중 기존 요청 종료,
실패 후 last-good/next-time, 명시적 disconnect/reconnect의 late 차단, 절전 후
한 번 조회 및 소비자 callback 중 stop의 timer 정리를 확인한다. Vue SSR로
한국어 countdown/배경 간격/실패의 마지막 관측과 다음 조회 표시도 확인한다.
창이나 실제 에이전트는 실행하지 않았다. 타입 검사·빌드와 기본 단위 테스트
770개(16 skip), 외부 DAG query를 포함한 단위 테스트 773개(13 skip)가 통과했다.

새 정책의 실제 Mac UI 카운트다운·5분 cadence·절전 복귀·자원 사용은 아직
미검증이다. 사용자가 업무를 마친 뒤 검증용 창 활성 전환을 허용하는 조건에서
별도로 확인해야 한다. 현재 다른 프로세스나 창을 조작하지 않는다.
실제 모델 요약의 안전한 실행·비용·품질·사용자 승인은 여전히 별도 게이트다.
