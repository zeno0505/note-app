# 연결 프로젝트 수동 AI 검증

공개 note-app 평가의 ‘현재 수동 Claude 사용 예외 누락’ 판정을 정정했습니다. 최초 모델 원문·생성 시각·저장 결과를 재생성하거나 수정하지 않았습니다. 그 외 품질에는 큰 이견이 없다는 사용자 피드백과 점진 적용 승인을 반영하여, 허용한 연결 프로젝트에 수동 Claude 요약을 연결했습니다.

## 구현과 실제 검증

- 제품 소스: `3f049e7302258dca46ee761fba68dc5e6d9e2371`, 트리 `f9fea46bcbc819653adc113350178ec29fde3237`. [해당 CI 성공](https://github.com/zeno0505/note-app/actions/runs/37497558506).
- 전체 단위 검사 955 pass / 16 skip, 타입·빌드 통과. 최종 설정·푸터·기존 후보 검토의 범위 설명은 관련 renderer 73개 검사 통과.
- 실제 Mac Electron 44.5.1 arm64 패키지: 71개 workstream 관측, Claude(Anthropic) 전송 안내·비밀키/개인정보 주의·탐지 한계 표시, 확인 전 AI 버튼 비활성, 확인 없는 실행 및 추가 경로 인자 거절.
- 화면 조회/확인란 변경/잘못된 IPC 요청은 모델 호출 0회. 기존 공개 요약의 네 섹션·검수 주석·입력 해시·생성 시각 복원, 동일 버튼 두 번의 추가 호출 0회.
- 760/1600 화면 가로 overflow 없음. macOS의 최소 창 폭보다 작은 화면 통과를 주장하지 않습니다.
- 검증 패키지를 기존 사용 경로에 설치하고 일반 실행 확인. 앱 SHA·main/preload hash·전체 dist 일치·서명 확인. 교체 중 사용자 profile 동일, 일반 실행 후 프로젝트 상태/이전 이력·읽기 권한·AI 캐시/ledger 보존. 기존 번들 백업과 복원용 사본 보존. 디버그 옵션 없이 실행.

실제 입력·개인 프로젝트 정보는 공개 보고서나 fixture에 포함하지 않습니다. 로컬 검증 근거는 `native-project-AI-3f049e7/report.json`, 설치 근거는 `app-update-project-AI-3f049e7/update-report.json`에 보관합니다.

## 판단 경계와 다음 확인

공개 파일럿 이후 새 유료 생성은 0회입니다. 연결 프로젝트의 실제 첫 생성 결과와 한국어 내용 품질은 아직 검증하지 않았습니다. 사용자가 선택한 프로젝트에서 수동 실행 후 네 섹션의 의미·누락·추정/사실 구분을 검수해야 합니다. 시험을 위해 모든 다른 프로젝트를 임의로 호출하지 않습니다. 필요 시 대상 하나와 생성 1회/형식 수정 최대 1회를 정한 뒤 확인합니다.

자동 호출·일괄 전송·개발 위임·기존 작업별 후보 승인 transport는 활성화하지 않았습니다. 허용 경로 전체를 재귀 수집하지 않고 현재 확인된 DAG·관측 설명과 이미 등록된 문서 발췌를 입력 한도 안에서 선별합니다. 미등록 문서나 연결되지 않은 PR/CI의 실제 근거까지 읽었다고 주장하지 않습니다.

수동 Claude 예외를 필수 입력/출력 근거로 검사하지만 JSON/필수 anchor 통과가 의미 전체의 진실성을 보장하지는 않습니다. T-033/T-034는 기존 의존성과 실제 내용 검토를 남긴 `in_review`입니다. 전체 Phase 1 개발 완료로 판단하지 않습니다.
