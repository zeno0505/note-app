## 현재 어디까지 구현되었나요?

소스에는 프로젝트 목록과 요약을 나누는 UI가 구현되어 있습니다. 목록에서 프로젝트를 선택하면 그 프로젝트의 요약이 별도 영역에 표시됩니다. 일반 앱의 '지금 요약'은 전체 설정 소스를 새로 읽는 규칙 기반 갱신입니다. 기존 production 모델 실행은 차단되어 있으므로 자동 모델 호출은 없습니다. 또한 CodeBurn 사용량 통계를 독립 /usage 경로로 분리했고, 프로젝트 현황에 있던 중복 패널은 제거했습니다. 실제 페이지 이동과 좁은 화면을 검증한 기록이 있습니다. 다만 T-028의 원래 의존성과 수용기준을 무시하고 이를 전체 완료로 바꾸지는 않습니다.

## 다음에는 무엇을 구현하나요?

다음 작업은 모두 계획 태스크입니다. Phase 2에서는 계정별 사용 한도와 메모리 여유·압력을 함께 고려해 동시 실행 수를 제어할 계획입니다. 이 밖에 T-029 쿼터·메모리 자원 정책, T-030 근거 있는 개발 위임, T-031 DAG 갱신 제안, T-032 트레이 최근 프로젝트가 계획되어 있습니다. 이번 공개 입력은 이들의 실제 구현을 입증하지 않습니다. 다른 note 프로젝트의 모델 연결은 공개 note-app 선행 실험 결과를 평가한 뒤 점진적으로 적용할 후속 작업입니다.

## 완료 판단에 어떤 근거가 있나요?

공개 소스 SHA 9243fee53ea151816289f651b09b7665b428316f의 CI 조회 결과는 성공입니다. workflow 환경은 Ubuntu 24.04와 Node 24.19.0이며, 타입 검사·단위 테스트·빌드를 실행합니다. 다만 CI 성공은 Mac GUI 검수와 별개입니다. Mac 근거는 별도 검증 기록에 있으며 배포 완료를 입증하지 않습니다. PR 병합도 테스트나 배포와 별개이므로 Phase 1 전체 완료로 확대하지 않습니다. 공개 Mac 검증 기록의 제품 source SHA는 7b0f42d90c1d51257db2afa503c148e7765bfb2d입니다. 이 기록에서 단위 테스트는 941개 통과, 16개 skip이고 타입 검사와 빌드도 통과했습니다. 실제 Orca 관측은 74개 작업이며 CodeBurn status/quota 조회는 성공했습니다. 입력 SHA와 실제 실행 앱 SHA는 같은 개념이 아닙니다. 따라서 이 기록으로 현재 앱 전체 상태를 추정하지 않습니다.

## 논의하거나 결정할 일이 있나요?

일반 읽기 요약에서 프로젝트별 설계 상태는 미기재입니다. 이 미기재를 결정 사항 없음이나 설계 완료로 바꾸지 않습니다. 2026-10-06에는 공개 note-app의 선별 근거만 기존 Claude 구독으로 보내는 수동 선행 실험 정책이 승인됐습니다. 조건은 동시 1개 실행, 생성 1회, 검증 실패 수정 최대 1회, 동일 입력 재호출 0, 최신 성공 본문 1개 유지입니다. 구현 진행과 승인 사실이 실험 내용의 정확성이나 일반 자동 실행의 완료를 뜻하지는 않습니다. 다른 프로젝트의 모델 전송 대상, 권한, 자동 실행 경계는 이번 공개 실험 뒤에 별도로 확인해야 합니다.
