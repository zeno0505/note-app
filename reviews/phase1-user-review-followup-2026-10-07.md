# Phase 1 사용자 검토 후속: 실행 버전과 프로젝트 요약

**전체 Phase 1은 in_review다.** 사용자 실제 실행 경로를 최신 검증 소스로 갱신했고, 기존 성공 본문은 보존했다. 투자자문 프로젝트에 저장된 AI 본문은 없으므로 AI 생성 성공으로 보고하지 않는다. Phase 2 T-036~048은 planning/pending이며 이번 변경에 제품 구현을 포함하지 않는다.

## 실제 버전 차이와 업데이트

이전 설치 검증은 `artifacts/87a28ca/note-app.app` 내부 `ba58eb2`, 일반 실행 PID78433에 해당한다. 후속 사용자 검토 시 유일한 실행 앱은 PID94565, `artifacts/b35bdfe/note-app.app` 내부 **87a28ca**였다. 이전 설치 성공을 현재 상태로 대체하지 않고 두 기록을 구분했다. 어떻게 구버전 복사본을 열었는지는 미확정이다.

구버전에는 일반 프로젝트 수동 Claude UI와 legacy 선택 커밋 형식 보완이 없었다. 긴 프로젝트의 `invalid_schema`와 투자자문의 규칙 버튼 관측에 영향을 주는 직접적인 버전 차이다. 단, 사용자 창을 통해 모든 증상 원인이 해소됐다는 수용 판정은 아직 없다.

두 경로 모두 **be805878e52edd8798fbabfcc003fa9700c0eae0**로 맞췄다. 사용자 실제 경로의 LaunchServices 일반 실행 PID43188이 하나뿐임을 확인했다. 서명, package/manifest SHA, main/preload 해시, 테스트 패키지와 전체 dist 파일 동일성, 디버그 옵션 없음도 확인했다. 빌드 이름은 폴더 이름과 다를 수 있으므로 앱 하단 `빌드 be80587`로 구분한다. 안내된 두 경로 외의 복사본이나 사용자 Dock 설정은 변경하지 않았다.

각 구버전은 별도 백업과 원래 경로 옆 보존 복사본에 남겼다. 교체 자체는 프로필을 변경하지 않았고, 일반 실행 뒤에도 기존 AI 본문/ledger·공개 파일럿·읽기 권한·프로젝트 상태/변경 시각·기존 이력 전체가 유지됐다. 이력 보존 정책은 기존 최신12개이며 무한 보존이 아니다. 구버전 설정에는 이미 승인된 Claude 실행 경로만 보완했고 나머지 설정은 동일했다. 새 읽기 root, 사용자 프로젝트 등록, 인증/보안 설정 변경은 없다.

## 좁은 표시 보완

- 전체 소스 버튼을 `규칙 요약 갱신 · 전체 소스`로 표시하고 AI 전송은 `지금 요약 · Claude AI`임을 안내한다. 실제 기능을 섞거나 규칙 갱신을 모델 성공으로 해석하지 않는다.
- 실제 canonical 노트 root/DAG 경로를 접힌 근거에 표시한다. 코드 저장소와 독립된 노트 저장소도 기존 허용 경로 안에서 별도 맥락으로 유지한다. 보존된 접근 미확인 경로는 현재 검증과 구분한다.
- CodeBurn 빈 집계와 실제 사용량0을 구분한다. 응답이 제공하는 `hasUsage=false`는 집계 기록 없음으로 표시한다. 이 Mac의 실제 status JSON에는 해당 필드가 없었으므로 unknown을 유지하고, 집계값0도 실제0 여부 미확인으로 표시한다. 쿼터에서 프로젝트 사용량/청구액을 추정하지 않는다.
- CLI stderr는 원문을 보관하거나 표시하지 않고 존재 여부만 진단에 남긴다. 오류 종류와 관측 시각은 기존 계약을 유지한다. 기본5초·출력 한도·취소·부분 실패/last-good 정책은 변경하지 않았다. CodeBurn 독립 수집 원인 조사는 별도 담당이며 SQLite 원인이나 timeout 원인을 확정하지 않았다.

## 사용자 확인과 남은 작업

현재 앱 하단 빌드를 확인한 뒤 `프로젝트 현황`의 프로젝트를 열면 저장된 AI 본문을 추가 호출 없이 읽을 수 있다. 접힌 `확인한 노트 맥락`은 실제 연결 root/DAG를 보여준다. 투자자문에 새 AI 본문을 원하면 전송 범위를 확인하고 **Claude AI 버튼**을 사용해야 한다. 전체 소스 규칙 갱신으로는 AI 본문이 생성되지 않는다.

- 계속 실행/검토: 세 실제 v2 결과의 사실/추정·누락·다음 작업 유용성 사용자 검수. 긴 프로젝트의 stale 저장 본문과 최신 입력을 구분한다.
- 필요 시 수동 실행: 투자자문 최신 입력의 Claude 생성·내용 검수. 현재는 성공 본문 없음이며 자동 재시도/임의 유료 호출은 하지 않았다.
- 별도 담당 계속 조사: CodeBurn 수집 기록 부재 원인과 비밀 원문 없는 진단. 설치/인증/설정은 변경하지 않는다.
- 적용 범위 결정/후속 검증: 현재 지속 foreground, 실제 sleep/wake·OS dialog, 최소 지원 OS·성능 목표. 과거 foreground2회 통과를 현재로 확대하지 않는다.
- 별도 보류: 기존 후보 production transport, Orca/Codex 모델 전송, 배포/notarization/main 병합. Phase2는 설계와 작업 등록만 완료했다.
