# Phase 2 실행 자원 계획

병렬 에이전트 파견은 계정별 사용 한도 관측과 Mac 메모리 여유·압력을 함께 고려하여 동시 실행 수와 대기를 결정한다. 이번 Phase 1 UI 변경에는 실행 스케줄러나 모델 호출을 추가하지 않는다.

- 제공자 사용률은 관측 정보다. 실행 허가와 강제 한도는 별도로 다룬다.
- 메모리 부족 시 새 작업을 대기시키거나 순차 실행한다. 사용자 작업을 강제로 종료하지 않는다.
- 실제 압력 수준, 작업별 메모리 추정치, 동시 실행 임계치와 회복 조건은 Phase 2에서 측정하고 설계한다. 지금 임의의 수치를 확정하지 않는다.
- 관측 실패·오래된 한도·정확한 프로젝트 귀속 실패를 사용량 0 또는 실행 가능으로 해석하지 않는다.
