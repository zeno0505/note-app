# Phase 1 프로젝트 수명 — 앱 소유 상태

사용자가 2026-10-06에 확정한 Phase 1을 구현한다. 프로젝트 완료·재개는 사용자만
전환하며 Orca 보관/에이전트 done/DAG done에서 자동 전환하지 않는다. 과거 계약의
startup/창 닫기 동작과 구별한다. 사용자 DAG와 노트에는 쓰지 않는다.

canonical host/DAG 식별자로 열린 워크트리를 중복 제거하여 앱에 등록한다. 지정된
`docs/note` 연결과 등록 scope/DAG 경계를 사용하는 기존 mapper를 재사용한다.
깨짐·모호함·경로 이탈은 미연결 상태로 표시한다. 전체 볼트 탐색은 없다.

등록된 프로젝트는 워크트리가 Orca에서 사라져도 유지한다. 등록 scope에 여전히
포함된 정확한 DAG를 조회하며 접근 불가는 별도로 표시한다. 등록 scope를 벗어난
캐시 경로를 읽지 않는다. 완료 프로젝트의 정기 DAG/문서/CI 조회는 제외하고,
명시적 지금 요약은 허용한다. 프로젝트의 조회 완료가 사용자 완료를 변경하지 않는다.

상태·마지막 요약/맥락·최근 12개 상태/요약 이력은 앱 private registry에 atomic cache
계약으로 저장한다. 사용자 노트의 날짜나 역사 문서 최신성을 판정하지 않는다.
최대 64개 프로젝트/32개 연결 워크트리/프로젝트, 기존 8개 DAG reader lifetime
상한은 유지한다. 상한이나 저장 실패는 성공으로 바꾸지 않는다. 자동 상태 저장도
사용자 노트/DAG 쓰기 권한을 의미하지 않는다.

비점유 단위/통합 검증과 실제 Mac 수용은 별개다. Finder `.app`, native 발견·완료/
재개·트레이·창 닫기와 배경 수집·절전·자원 검증은 최종 SHA의 별도 수용 게이트이다.
