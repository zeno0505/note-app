# DAG 접두사별 요약

처음에는 `T`를 선택한다. 실제 ID의 `접두사-숫자[문자 접미사]` 형식에서 접두사를 추출한다. `T-227`, `MP-002c`, 숫자 하위 작업 `T-019a-1`을 지원하며 `T`와 `TT`는 다른 범위이다. 형식 미지원 ID의 개수도 별도로 표시한다. `T`가 없으면 빈 선택 범위를 유지하고 AI 버튼을 막는다. 다른 실제 접두사를 사용자가 직접 선택해야 한다.

선택은 앱 소유 프로젝트 등록 파일의 선택적 `summaryPrefix`와 `summaryTaskIds` 필드에 저장한다. 노트 원본, 링크, 읽기 허용 목록은 수정하지 않는다. 같은 DAG의 재연결과 프로세스 재시작에서도 명시한 선택을 복원한다. 다른 DAG는 자신의 선택 또는 초기 `T`를 사용한다.

전체 검증된 read model에서 접두사를 먼저 필터링한 뒤, 규칙과 AI가 같은 최대 20개 작업을 사용한다. 대표 모드는 진행·차단·검토·착수 후보·그 밖의 미완료·완료 범주를 최대 5회 순회하며 대표를 확보한 뒤 빈 자리를 채운다. 범주 안에서는 기다리는 미완료 직접 후속 작업 수를 우선하고 동률은 원문 순서다. ID 번호·원문 위치·파일 시각을 최신 작업 시각으로 해석하지 않는다.

명시 선택은 현재 접두사의 실제 ID 1~20개로 제한하며 대표 선정보다 우선한다. 화면의 DAG/선택 목록은 선택 작업을 우선 포함해 최대 200개이며 목록 밖 ID는 정확히 입력할 수 있다. 문장별 작업 이름은 5개까지 설명한다. 선택/생략 수, 이유, 없는 선택 ID를 공개한다. 사라진 ID를 자동 대체하지 않으며 수정 전 AI를 막는다. 접두사 전환은 대표 모드로 돌아간다. 입력 바이트 상한을 넘으면 호출 전에 중단한다. 자세한 현재 수락기준은 [작업 단위 요약 품질](summary-task-quality.md)을 따른다.

다른 접두사의 작업 본문은 포함하지 않는다. 선택 작업이 연결하는 선택 밖의 내부 의존성(같은 접두사 포함)은 ID·내부 구분·선언 상태만, 외부 의존성은 ID·외부 구분·상태 미확인만 남긴다. 규칙 문장은 의존성 메타데이터 8개를 표시하고 나머지 개수를 알린다. 외부 의존성 충족이나 실제 구현·테스트·배포 완료를 추정하지 않는다.

접두사와 작업의 대응이 명시되지 않은 프로젝트 문서, 등록 발췌문, 프로젝트 전체 PR·CI 본문은 현재 접두사 요약 입력에서 제외한다. 기존 문서 등록과 이전 기록을 삭제하지 않는다. 작업과 연결된 별도의 실제 검수 근거를 결합하는 작업은 이후 범위이다.

규칙 캐시는 워크스트림·DAG·접두사로 구분한다. AI 저장 키는 호스트·정규 DAG 경로·`task-scope-v1`·접두사·정렬된 직접선택 ID 또는 대표모드로 만든다. 성공 본문, 실패 예약, 진단 재시도 예약, 입력 해시는 이 저장 키를 사용한다. 선택 작업과 연결 의존성으로 만든 근거 해시에는 다른 접두사의 무관한 본문을 넣지 않는다. 전환하면 동의 체크박스와 현재 UI 실행 상태를 초기화하고 진행 중인 요청을 취소한다. 늦은 결과는 재검증을 통과하지 못하면 저장하지 않는다.

기존 전역 및 prefix-v1 AI 저장 파일과 실패 예약은 그대로 보존하며 현재 선택의 결과로 읽지 않는다. 이전 프로젝트 전체 규칙 이력과 6관점 후보·승인 기록은 이전 기록으로 표시하며 현재 접두사의 검증 근거로 승격하지 않는다. 6관점 이력은 읽기 전용으로 유지한다. 프로세스 재시작 뒤 이미 저장된 접두사 결과도 새 입력과 재검증되기 전에는 역사적 결과로 표시한다. 화면 조회나 접두사 전환은 모델을 호출하지 않는다.

## 검증

- `npm run check`: 타입 검사, 전체 단위 테스트, 빌드.
- `npm run test:electron:prefix`: 격리된 가상 DAG와 실제 host/preload/renderer에서 기본 T, 정확한 전환, 200개 상한 뒤의 작업, T 부재, 동의 초기화, 재연결, 재시작, 밝은/어두운 Select 화면을 검증한다. 모델 실행을 차단하며 사용자 자료를 사용하지 않는다.
- `project-model.test.ts`: 접두사별 입력/캐시/실패 예약 분리, 이전 결과 보존, 취소와 늦은 합성 응답의 저장 차단을 검증한다. 모델 어댑터는 합성이다.

이 검증은 실제 모델의 한국어 요약 내용 수용이나 Phase 1 전체 완료를 증명하지 않는다. 실제 모델 호출·main 병합·배포는 이 변경의 검증에 포함하지 않는다.

같은 프로젝트·DAG·접두사의 정기 관측은 열린 선택 모달·초안을 유지한다. 실제 identity 변경만 편집을 취소한다. 저장 성공 acknowledgement와 최신 관측 적용은 분리하여 publish event가 응답보다 먼저 와도 성공을 실패로 표시하지 않는다.
