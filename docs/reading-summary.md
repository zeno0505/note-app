# 규칙 기반 프로젝트 읽기 요약

앱에서 명시적으로 연결한 읽기 소스의 관측을 네 섹션의 한국어 문장으로 설명한다.
모델 호출, 사용자 DAG/노트 수정, 사용자 승인 기록 생성은 없다. 기존 여섯 관점의
저장된 모델 후보와 과거 승인 요약은 기존 계약과 화면에 그대로 남는다.

## 표시와 수용 기준

- 현재 구현 범위: 완료·진행 중인 DAG **선언**과 연결된 PR의 관측을 구분한다.
  완료 선언, 에이전트 done, PR 병합은 테스트·화면 검수·배포 성공으로 승격하지 않는다.
- 다음 구현: 표시 범위에서 내부 의존성 완료 선언을 확인한 pending 작업만 후보로
  설명한다. 외부/생략/미확인 의존성은 충족했다고 가정하지 않는다. 우선순위와
  설계 합의, 실행 승인은 미확인으로 남긴다.
- 판단 근거: PR head SHA의 CI·리뷰와 병합 SHA를 구별한다. 옛 SHA 리뷰는 현재
  승인으로 사용하지 않는다. 화면·테스트 코드 실행·배포는 입력이 없어 미확인이다.
- 논의할 일: blocked 선언을 표시한다. 설계가 끝났다는 명시적 근거가 없는 작업을
  구현만 남은 것으로 해석하지 않는다.

출처 식별자, DAG 원문 해시, 해당 커밋 SHA와 관측 시각을 유지하며 없는 값은
미확인이다. sourceHash와 커밋 SHA는 서로 다른 개념이다. 고정 규칙은 기능의 실제
동작·사용자 의도·설계 논의를 이해하거나 검증하지 못한다. 이 설명은 모델 응답이나
사용자 승인 요약이 아니며, 그 계약의 claim/assertion 필드를 확대하지 않는다.

## 수집과 설명 갱신

수집은 기존 snapshot store가 소유한다: 앱 실행 중 연결된 비보관 작업만 대상으로,
포어그라운드 20초/백그라운드 5분/복귀 5초 대기와 수동 조회가 유지된다. 완료한
관측은 별도 reading scheduler에 전달된다. scheduler는 자체 반복 타이머나
앱 종료 후 서비스를 만들지 않는다. 모델 실행 큐와도 연결하지 않는다.

`실제 소스 새로고침`은 수집 요청, `지금 요약`은 최신 관측을 확인하고 읽기 설명을
갱신하는 별도 IPC/버튼이다. 둘 다 진행 중인 수집에 합류한다. 연결되지 않았으면
실행하지 않는다. 텍스트/작업 선언/의존성/표시 범위/PR·CI·리뷰/관측 성공 여부가
바뀔 때만 설명 revision과 generatedAt을 바꾼다. 관측 시각, DAG mtime, 표시된
projection 밖의 DAG 원문 해시만 달라지면 설명을 유지한다. checkedAt은 새 확인
시각이며 기존 인용의 관측 시각은 덮어쓰지 않는다. 연결 해제 후 같은 근거를 다시
관측해도 재생성하지 않는다. 사라진 작업의 캐시는 다음 성공 관측에서 제거한다.

수집 실패에는 이전 전체 관측과 설명을 stale로 보존한다. PR 조회 실패에는 동일
workstream/DAG의 마지막 PR 근거를 **이전 관측**으로 표시하고 현재 완료 대조에
사용하지 않는다. 연결 해제·dispose·범위 교체는 늦은 요약 결과의 게시를 막는다.
요약은 앱 메모리에만 저장되며 기존 승인 캐시를 생성하거나 변경하지 않는다.

## 외부 PR 어댑터: 합성 테스트 경계

`PullObservationAdapter`는 main 내부의 시험용 seam이다. production GitHub
transport, 저장소 자동 검색, 자격 증명 경로, 사용자 입력 URL 실행 기능은 없다.
실제 조회 대상 및 작업/회차/커밋 연결 정책 승인 후에만 구체 어댑터를 추가한다.
현재 production에서는 PR/CI/리뷰가 미설정이라고 표시한다.

응답은 workstream/DAG와 정확히 일치해야 한다. repository 이름, PR 번호, head/merge
SHA, 작업 연결 상태, CI/review SHA, 관측 시각, coverage를 엄격하게 검사한다.
`verified` 연결은 어댑터가 제공하는 계약이며 이 parser 자체가 GitHub나 커밋 대응을
인증한 결과는 아니다. unresolved/squash-unverified/표시 범위 밖 task는 특정 작업
완료 근거에 사용하지 않는다. 부분 조회와 빈 조회는 전체 부재·완료가 아니다.

상한: batch 1,000 workstreams, 외부 조회 최대 8회/총 대기 5초, 응답 128 KiB,
PR 32개/문장 표시 8개, PR당 task/CI/review 32개, 작업 이름 문장 표시 5개.
5분보다 오래된 또는 미래 PR 관측은 현재 조회로 받지 않는다. 취소/시간 제한에
걸린 어댑터는 실제 IO 종료를 검증할 수 없으므로 lifetime 재사용을 차단한다.
late promise는 받아도 게시하지 않으며 무제한 재시도를 만들지 않는다. 이 경계는
실제 네트워크 소켓 강제 종료 증명이 아니다.

track-dag-stack의 query/Git/PR 대조 절차는 향후 관측 어댑터의 참고가 될 수 있다.
그 skill 전체는 set.py·execution-log·dag.md 갱신을 포함하므로 자동 실행하지 않는다.
기존 official query pin은 유지한다. 회차/PR 선언 projection 확대와 실제 GitHub
관측 권한은 별도이며, 병합을 그 skill의 done·검수·배포 상태로 자동 변환하지 않는다.
