# T-028 · CodeBurn 사용량 통계 페이지 분리

상태: **pending** · 등록일: 2026-10-06 · 기존 note-app 로컬 작업 DAG의 후속 태스크.
의존성: T-022(UI와 로컬 read-model 연결), T-027(실제 Electron 검증 인프라).
이 문서는 같은 T-028의 공개 계획 요약이며 별도 태스크가 아니다.

사용자는 프로젝트별 AI 요약을 후속으로 작업한다는 전제에서 현재 UI 구조가 Phase 1을 충분히 반영한다고 수용했다. 이 수용은 UI 구조에 한정되며 기존 검증 태스크 또는 Phase 1 전체 검증을 자동 완료하지 않는다. 프로젝트별 AI 요약과 모델 전송 범위는 후속 작업에서 다룬다.

이번 요청은 태스크 등록이다. 제품 코드 변경, 앱 업데이트, 모델 호출은 포함하지 않는다.

## 완료 기준

- 최상단 내비게이션을 **프로젝트 현황 → 사용량 통계 → 연결 및 설정** 순서로 구성하고 사용량 통계에 독립 페이지/라우트를 제공한다.
- 기존 CodeBurn 사용량·쿼터 표시를 새 페이지로 이전한다. 프로젝트 현황의 중복 표시를 제거해 정보량을 줄이고 관측 시각, freshness, 부분 실패/timeout, 미확인 안내를 보존한다.
- 사용량(토큰·횟수·관측된 비용 등)과 계정 쿼터(구간별 사용률·리셋 시각 등)를 구분한다. 조회 실패나 미확인을 0 사용량 또는 에이전트 실행 가능 보장으로 표시하지 않는다.
- 기존 읽기 전용 수집 상태를 재사용한다. 페이지 전환으로 중복 수집, 추가 모델 호출, 새 권한 요청이 발생하지 않는다.
- 실제 Mac 패키지 앱에서 세 페이지 전환·돌아오기, 내비게이션 순서, 사용량/쿼터와 부분 실패 표시, 좁은 창의 잘림·겹침을 검증한다. 스크린샷 시각 검토, 앱 SHA, 환경, 정확한 명령·로그를 기록한다.
- 타입 검사와 관련 단위·회귀 검증을 완료한다. 실제 Mac 검증이 막히면 미검증으로 남긴다. 태스크 등록이나 UI 수용만으로 done 처리하지 않는다.

예상 변경 범위는 renderer 내비게이션/라우트, Overview의 CodeBurn 표시 위치, 기존 LiveCodeBurn 컴포넌트 재사용, 관련 테스트와 Mac 검증 기록이다. 구현은 후속 사용자 지시에서 수행한다.
