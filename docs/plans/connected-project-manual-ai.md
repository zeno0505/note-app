# 연결 프로젝트 수동 Claude 요약

공개 note-app 파일럿의 원문·저장 결과는 유지하며, 연결된 각 프로젝트에 `지금 요약 · Claude AI`를 제공합니다. 전체 소스 갱신은 기존 규칙 기반 관측입니다. 프로젝트의 수동 AI, 자동 호출 없음, 기존 후보 승인 워크플로의 차단 범위를 화면과 입력에서 함께 설명합니다.

## 실행과 자료 경계

- 기존 로그인된 Claude(Anthropic) 구독 CLI를 사용합니다. 기존 절대 실행 경로 설정 `publicModelClaudePath`가 수동 프로젝트 요약도 활성화합니다. 외부 도구·파일 탐색·MCP·브라우저·추가 설정·세션 저장은 차단합니다.
- 사용자 읽기 허용 목록과 실제 프로젝트/DAG 매핑을 다시 검증합니다. Renderer는 현재 workstream ID와 전송 안내 확인 여부만 보냅니다. 경로·프롬프트·모델·환경을 지정할 수 없습니다.
- 확인된 DAG 태스크, 프로젝트의 규칙 기반 PR·CI·리뷰/문서 설명, 이미 등록된 문서 발췌만 한도 안에서 선별합니다. DAG는 진행/차단/검토 상태와 최근 태스크 번호 우선 최대 24개, 설명은 섹션별 3개, 등록 발췌는 최대 4개입니다. 전체 JSON 48KB/출처 12개/필수 사실 24개 한도를 유지하며 생략을 명시합니다. 임의 홈/인증/다른 노트 탐색, 재귀 수집, 일괄 호출은 없습니다.
- 태스크·문서 원문에서 명백한 키·토큰·개인키·이메일·휴대전화·주민등록번호, credential 파일명 등을 검사하며 발견 또는 검사 실패 시 전송을 중단합니다. 이 검사는 모든 개인정보를 알아내는 보장이 아닙니다. 폴더 허용과 AI 사용 전에 한국어 경고·전송 확인을 표시합니다. 오류에는 원문을 포함하지 않습니다.
- 입력 SHA 필드는 일반 프로젝트에서 Git 커밋이 아닌 선별 내용 지문의 앞 40자리입니다. UI는 일반 프로젝트 입력 해시로 표시하여 Git SHA와 혼동하지 않습니다.

## 호출과 저장

공개·연결 프로젝트는 동일 전역 슬롯과 기존 durable ledger를 사용합니다. 서로 다른 프로젝트는 동시에 호출하지 않으며 대기 중인 다른 프로젝트를 취소하지 않습니다. 동일 프로젝트의 다른 입력은 이전 요청을 폐기합니다. 생성 1회, 정상 응답의 형식·필수 근거 검사 실패에 한해 수정 최대 1회입니다. 실패·취소·중단 기록은 자동 재호출하지 않습니다.

프로젝트 ID는 로컬 호스트와 정규 DAG 경로를 묶은 해시이며 경로 자체를 전송하거나 저장 결과에 표시하지 않습니다. 관측 시간과 polling은 입력 지문에서 제외합니다. 프로젝트별 최신 성공 본문 1개, 최소 호출 방지 기록은 별도 보존합니다. 공개 파일럿 계약/입력 해시는 그대로 유지됩니다. 권한 철회·연결 해제·현재 근거 변경·취소·종료에서 요청을 취소하며 송신 직전과 응답 게시 직전에 현재 매핑·내용을 다시 검증합니다.

## 검증과 남은 실제 확인

구현 시 전체 단위 검사 955 통과/16 skip, 타입 검사와 빌드 통과. 이후 설정/푸터/후보 검토 UI의 범위 설명 변경은 관련 renderer 73개 검사와 타입·빌드로 확인했습니다. 공개/합성 fixture로 프로젝트 격리, 재시작 재사용, 이전 성공 보존, 동시 호출 제한, 민감정보 차단, 경로 탈출, 늦은 결과 차단과 수동 실행 예외 누락을 검사했습니다.

다른 실제 프로젝트의 자료 전송/유료 호출은 테스트 목적으로 실행하지 않았습니다. 실제 Mac 패키지에서 경고·확인 전 버튼 비활성화·잘못된 IPC 인자 거절·기존 공개 본문/생성 시각 복원·추가 모델 호출 0회를 확인했습니다. 760/1600 화면 가로 overflow가 없었으며 새 패키지와 설치 dist가 일치하고 일반 실행 상태·프로젝트 이력·읽기 권한·AI cache/ledger가 보존됐습니다. 코드 SHA `3f049e7302258dca46ee761fba68dc5e6d9e2371`의 CI `37497558506`도 성공했습니다. 실제 생성이 필요하면 대상 프로젝트와 생성 1회/형식 수정 최대 1회의 비용 범위를 정한 뒤 사용자 수동 실행으로 확인합니다. JSON/필수 출처 검사 통과만으로 한국어 의미의 정확성이나 전체 Phase 1 완료를 선언하지 않습니다.

## 실제 생성 후 입력 계약 v2 보완

일반 경로의 첫 실제 note-app 요약은 생성 1회/수정 0회, 동일 입력과 재시작 추가 호출 0회로 저장됐습니다. 의미 검수에서는 결정 섹션의 과거 승인 필요 기록과 현재 수동 승인 범위 구분이 부족했고, 앞 번호 태스크와 오래된 문서가 최근 작업/현재 CI보다 우선했습니다. 원문은 보존했습니다.

연결 프로젝트 입력 계약 v2는 구현/결정 두 섹션에 현재 수동 Claude 승인과 기존 후보/자동 실행 제한을 필수 근거로 넣습니다. 현재 CI·PR·리뷰를 먼저, DAG의 진행·차단·최근 검토 작업을 먼저 선별합니다. 등록 문서의 미대조 기록은 현재 미구현·미승인 판정으로 바꾸지 못하도록 명시합니다. 기존 v1 저장 본문과 ledger는 유지하며 새 입력 검증이 필요한 이전 결과로 표시합니다. 공개 파일럿 계약/원문은 변경하지 않습니다.
