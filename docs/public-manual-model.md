# 공개 note-app 수동 AI 선행 실험

2026-10-06 승인 범위는 공개 note-app 선별 근거를 기존 로그인 Claude 구독으로 수동 요약하고 내용을 평가하는 것이다. 다른 note 프로젝트와 변경 시 자동 호출은 이후 사용자 평가·결정 범위다.

선택 상세와 설정의 공개 note-app 영역에 `지금 요약 · 공개 note-app AI`를 제공한다. 화면 열기·일반 전체 소스 갱신·폴링·페이지 이동은 모델을 호출하지 않는다. 시작 설정의 `publicModelClaudePath`가 없으면 실행은 비활성이다. 경로는 trusted main 설정의 절대 경로만 허용하며 renderer는 프로젝트/파일/프롬프트/제공자 인수를 전달할 수 없다.

입력은 앱에 포함한 `src/shared/public-reading-pack.json` 한 개다. 공개 feature SHA `9243fee53ea151816289f651b09b7665b428316f`의 12개 선별 소스·9개 사실, 15,529 UTF-8 bytes이며 입력 hash는 `9c4536398951fdd040216c1d8d8d13a9d2e217c0d00b938826fc59eb94d8bd4e`다. 항목의 공개 경로/줄 범위/발췌 hash와 exact-SHA CI를 준비 단계에서 확인했다. 개인 노트·다른 프로젝트 경로·자격증명은 입력에 포함하지 않는다. 공개 검증 기록 한 파일만 소스 allowlist에 추가했으며 다른 reviews 경로는 여전히 거부한다.

이 입력은 고정된 공개 스냅샷이다. 제품 구현 SHA·실행 앱 SHA·입력 SHA는 구분한다. 브랜치의 후속 변경이나 원본 노트 전체를 현재 입력으로 추정하지 않는다. 내용 변화가 없는 버튼 재실행과 재시작은 durable ledger를 재사용하므로 추가 모델 요청이 없다.

기존 하네스의 전역 실행 슬롯 1개, 입력당 생성 1회·완료 응답 검증 실패 수정 최대 1회, 취소/deadline/늦은 결과 차단과 최신 성공 본문 1개 저장을 재사용한다. 실패·취소·다른 입력은 이전 성공을 보존하고 stale 상태로 표시한다. 도구와 MCP는 비활성, 설정 탐색은 제한하며 API 환경 변수는 구독 CLI에 상속하지 않는다. 불확실한 제출이나 timeout은 자동 재전송하지 않는다.

검증: 타입 검사·관련 55개 테스트·전체 947 pass/16 skip·빌드가 통과했다. 실제 패키지의 수동 실행은 생성 1회/수정 0회/동일 버튼 추가 호출 0회였고 네 섹션을 표시·저장했다. [실제 출력과 별도 내용 평가](../reviews/public-manual-model-2026-10-06.md)는 사용자 검토 대기 상태다. 관련 DAG에서는 T-033 in_review로 기록하며 JSON/필수 anchor 검사 성공을 문맥 정확성이나 Phase 1 전체 완료로 바꾸지 않는다.
